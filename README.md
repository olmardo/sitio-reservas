# sitio-reservas

Sitio de reservas de Grupo Olmardo, una empresa ficticia. Se publica en reservas.olmardo.com.

Es un repositorio de prueba del proyecto LowTide (Tec de Monterrey), que busca exposiciones en su dominio de prueba, olmardo.com. El token de `config/despliegue.env` es inventado a propósito: empieza con `CIRDAN_FAKE_` y no abre nada.
